# roulette Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single POSIX shell script that lets one person switch Claude Code between their own subscription accounts in seconds, keep conversation context across the switch, and see each account's login and usage.

**Architecture:** One script, `roulette`, with one function per subcommand. Tokens live in the macOS Keychain behind three `secret_*` functions. Non-secret state (account list, detected usernames, usage snapshots) lives in a JSON file updated atomically with `jq`. Usage data comes from Claude Code's status line payload via `roulette statusline-hook`. All table rendering and ranking logic is a shared jq library string (`JQ_LIB`).

**Tech Stack:** POSIX sh (must run under macOS `/bin/sh`, bash 3.2 in POSIX mode), `jq` ≥ 1.6, macOS `security`, `bats-core` for tests, `shellcheck`.

**Spec:** `docs/superpowers/specs/2026-09-24-roulette-design.md`

## Global Constraints

- Runtime dependencies: `/bin/sh`, `jq`, macOS `security`, `claude`. Nothing else.
- Tokens are never written to disk by roulette, never printed, never passed as a command-line argument (use `security -i` over stdin).
- State file: `${ROULETTE_CONFIG_DIR:-${XDG_CONFIG_HOME:-$HOME/.config}/roulette}/state.json`, shape `{"accounts":[],"usernames":{},"usage":{}}`. No secrets in it.
- Every state write: temp file in the same directory, then `mv`.
- roulette never switches accounts without the user running a command. No retry-on-another-account, no background rotation.
- Account names: `[A-Za-z0-9_-]+` only.
- Keychain entries: service `roulette:<name>`, account `$USER`.
- `statusline-hook` must always exit 0 and must never suppress the chained command's output.
- Do not use `set -u` or bash-only syntax (no `[[`, arrays, `local`, `$'…'`).
- No Claude/Anthropic trademark in the project name; no Co-Authored-By lines in commits.

## Review Focus

1. **`claude auth status` may ignore `CLAUDE_CODE_OAUTH_TOKEN`** and report the machine's stored login for every account. Expected: roulette warns when two accounts report the same username (Task 2 test "warns when two accounts report the same login").
2. **A stray `ANTHROPIC_API_KEY` in the user's shell** would override the account token, so every "account" silently bills the API key. Expected: `use` unsets `ANTHROPIC_API_KEY` and `ANTHROPIC_AUTH_TOKEN` for the child (Task 3 test "clears API key env vars").
3. **Malformed or empty status line payload / missing state dir** must not blank the user's status line. Expected: chained output still printed, exit 0 (Task 4 test "malformed payload still prints chained output").
4. **Pasted token with trailing newline or spaces** (copying from a terminal). Expected: whitespace trimmed before storing (Task 2 test "trims whitespace from pasted token").
5. **`next` run from inside a roulette session or with a single account.** Expected: current account excluded; with nothing else, a clear message and exit 1 without launching (Task 5 tests "excludes the current account", "no other accounts").

```sh
#!/bin/sh
# Test double for macOS `security`, backed by files in $FAKE_KEYCHAIN.
printf '%s\n' "$*" >> "$FAKE_KEYCHAIN/.argv"
if [ "${1:-}" = -i ]; then
  IFS= read -r line || exit 1
  # shellcheck disable=SC2086
  set -- $line
fi
cmd=${1:-}
[ $# -gt 0 ] && shift
svc= pw= want_pw=0
while [ $# -gt 0 ]; do
  case $1 in
    -s) svc=$2; shift 2 ;;
    -a) shift 2 ;;
    -w)
      if [ "$cmd" = add-generic-password ]; then pw=$2; shift 2
      else want_pw=1; shift
      fi ;;
    *) shift ;;
  esac
done
file="$FAKE_KEYCHAIN/$(printf '%s' "$svc" | tr ':/' '__')"
case $cmd in
  add-generic-password) printf '%s' "$pw" > "$file" ;;
  find-generic-password)
    [ -f "$file" ] || exit 44
    if [ "$want_pw" -eq 1 ]; then cat "$file"; echo; fi ;;
  delete-generic-password)
    [ -f "$file" ] || exit 44
    rm -f "$file" ;;
  *) exit 2 ;;
esac
```

```sh
#!/bin/sh
# roulette — switch Claude Code between your own subscription accounts.
#
# Tokens live in the macOS Keychain (service "roulette:<name>").
# Everything else lives in $CONFIG_DIR/state.json and is never secret.

ROULETTE_VERSION=0.1.0
CONFIG_DIR=${ROULETTE_CONFIG_DIR:-${XDG_CONFIG_HOME:-$HOME/.config}/roulette}
STATE=$CONFIG_DIR/state.json
EMPTY_STATE='{"accounts":[],"usernames":{},"usage":{}}'

die() {
  printf 'roulette: %s\n' "$*" >&2
  exit 1
}

now() {
  printf '%s\n' "${ROULETTE_NOW:-$(date +%s)}"
}

need_jq() {
  command -v jq >/dev/null 2>&1 || die "jq is required. Install it with: brew install jq"
}

valid_name() {
  case $1 in
    '' | *[!A-Za-z0-9_-]*) return 1 ;;
  esac
  return 0
}

# --- secrets: macOS Keychain. Linux support = reimplement these three. ---

secret_set() {
  # Fed through `security -i` on stdin so the token never shows up in `ps`.
  printf 'add-generic-password -U -a %s -s roulette:%s -w %s\n' "$USER" "$1" "$2" |
    security -i >/dev/null 2>&1
}

secret_get() {
  security find-generic-password -a "$USER" -s "roulette:$1" -w 2>/dev/null
}

secret_del() {
  security delete-generic-password -a "$USER" -s "roulette:$1" >/dev/null 2>&1
}

# --- state ---

state_read() {
  if [ ! -f "$STATE" ]; then
    printf '%s\n' "$EMPTY_STATE"
    return 0
  fi
  jq -e . "$STATE" >/dev/null 2>&1 || die "state file is corrupt: $STATE"
  cat "$STATE"
}

# state_update <jq filter> [jq args...] — atomic read-modify-write.
state_update() {
  _su_filter=$1
  shift
  _su_state=$(state_read) || return 1
  mkdir -p "$CONFIG_DIR" || return 1
  _su_tmp=$(mktemp "$CONFIG_DIR/.state.XXXXXX") || return 1
  if printf '%s\n' "$_su_state" | jq "$@" "$_su_filter" >"$_su_tmp" 2>/dev/null && [ -s "$_su_tmp" ]; then
    mv "$_su_tmp" "$STATE"
  else
    rm -f "$_su_tmp"
    return 1
  fi
}

has_account() {
  state_read | jq -e --arg n "$1" 'any(.accounts[]; . == $n)' >/dev/null 2>&1
}

require_account() {
  has_account "$1" && return 0
  _ra_names=$(state_read | jq -r '.accounts | join(", ")')
  [ -n "$_ra_names" ] || die "no accounts yet. Add one with: roulette add <name>"
  die "unknown account '$1'. Accounts: $_ra_names"
}

# --- shared jq library: formatting, usage estimates, ranking ---

JQ_LIB='
def pad($w): tostring | . + (" " * ([$w - length, 0] | max));
def lpad($w): tostring | (" " * ([$w - length, 0] | max)) + .;
def bar($p): [range(8)] | map(if . < (($p / 12.5) | round) then "▰" else "▱" end) | join("");
def cell($v; $est):
  if $v == null then ("?" | pad(14))
  else bar($v) + " " + (($v | round | tostring) + "%" | lpad(4)) + (if $est then "~" else " " end)
  end;
def eff($now):
  if . == null then {five: null, seven: null, seen: null, est5: false, est7: false}
  else ($now - .seen) as $age
    | (((.resets_at | type) == "number") and ($now >= .resets_at)) as $reset
    | {seen: .seen,
       est5: ($age > 18000 or $reset),
       est7: ($age > 604800),
       five: (if ($age > 18000 or $reset) then 0 else .five_hour end),
       seven: (if $age > 604800 then 0 else .seven_day end)}
  end;
def rows($now):
  . as $s | [.accounts[] as $n | {name: $n, username: $s.usernames[$n]} + ($s.usage[$n] | eff($now))];
def ago($now):
  if . == null then "never"
  else ($now - .) as $d
    | if $d < 60 then "now"
      elif $d < 3600 then "\($d / 60 | floor)m ago"
      elif $d < 86400 then "\($d / 3600 | floor)h ago"
      else "\($d / 86400 | floor)d ago" end
  end;
def ranked($now; $cur):
  rows($now)
  | map(select(.name != $cur and ((.seven // 0) < 100)))
  | sort_by((if .five == null then 50 elif .five < 50 then .five else .five + 1 end), (.seen // 0));
'

# --- commands ---

cmd_list() {
  _st=$(state_read) || exit 1
  printf '%s\n' "$_st" | jq -r --arg cur "${ROULETTE_ACCOUNT:-}" '
    if (.accounts | length) == 0 then "no accounts yet. Add one with: roulette add <name>"
    else . as $s
      | ([.accounts[] | length, 4] | max) as $w
      | .accounts[] as $n
      | (if $n == $cur then "* " else "  " end)
        + ($n + (" " * ([$w - ($n | length), 0] | max))) + "  "
        + ($s.usernames[$n] // "(unknown)")
    end'
}

usage() {
  cat <<'EOF'
roulette — switch Claude Code between your own subscription accounts

  roulette add <name> [--force]          store an account's token (from `claude setup-token`)
  roulette use <name> [claude args...]   launch claude on that account
  roulette next [claude args...]         pick another account and continue the last conversation
  roulette status                        usage per account
  roulette list                          accounts and their logins
  roulette refresh <name>                re-detect an account's login
  roulette remove <name>                 forget an account
  roulette statusline-hook [-- <cmd>...] status line integration (see README)
EOF
}

main() {
  _cmd=${1:-help}
  [ $# -gt 0 ] && shift
  case $_cmd in
    help | -h | --help) usage; return 0 ;;
    version | --version) printf 'roulette %s\n' "$ROULETTE_VERSION"; return 0 ;;
  esac
  need_jq
  case $_cmd in
    list) cmd_list "$@" ;;
    *)
      printf 'roulette: unknown command: %s\n\n' "$_cmd" >&2
      usage >&2
      exit 1
      ;;
  esac
}

main "$@"
```

```sh
# --- account identity ---

# detect_username <token> — prints the account's email, or nothing.
# The field name in `claude auth status --json` is not documented, so try the likely ones.
detect_username() {
  CLAUDE_CODE_OAUTH_TOKEN=$1 claude auth status --json 2>/dev/null |
    jq -r '[.email, .emailAddress, .account.email, .account.emailAddress, .user.email]
           | map(select(type == "string" and . != "")) | first // empty' 2>/dev/null
}

# set_username <name> <token>
set_username() {
  _su_user=$(detect_username "$2")
  if [ -z "$_su_user" ]; then
    state_update '.usernames[$n] = null' --arg n "$1" || die "could not update $STATE"
    printf "%s → (unknown — run 'roulette refresh %s')\n" "$1" "$1"
    return 0
  fi
  state_update '.usernames[$n] = $u' --arg n "$1" --arg u "$_su_user" || die "could not update $STATE"
  printf '%s → %s\n' "$1" "$_su_user"
  _su_dupe=$(state_read | jq -r --arg n "$1" --arg u "$_su_user" \
    '.usernames | to_entries[] | select(.key != $n and .value == $u) | .key' | head -n 1)
  if [ -n "$_su_dupe" ]; then
    printf "roulette: warning: '%s' reports the same login as '%s'. Did you sign in to the right account when running 'claude setup-token'?\n" "$1" "$_su_dupe" >&2
  fi
  return 0
}

cmd_add() {
  _force=0
  _name=
  for _a in "$@"; do
    case $_a in
      --force) _force=1 ;;
      -*) die "unknown option: $_a" ;;
      *)
        [ -z "$_name" ] || die "usage: roulette add <name> [--force]"
        _name=$_a
        ;;
    esac
  done
  [ -n "$_name" ] || die "usage: roulette add <name> [--force]"
  valid_name "$_name" || die "account names may only use letters, digits, '-' and '_'"
  if [ "$_force" -eq 0 ] && has_account "$_name"; then
    die "account '$_name' already exists (use --force to replace its token)"
  fi

  cat >&2 <<EOF
Run this in another terminal and sign in, in the browser, as the account you want to call '$_name':

    claude setup-token
```

```sh
# Other providers (see spec) would branch here.
launch_account() {
  _la_name=$1
  shift
  _la_token=$(secret_get "$_la_name")
  [ -n "$_la_token" ] || die "no keychain entry for '$_la_name'. Re-add it with: roulette add $_la_name --force"
  # An API key in the environment would take precedence over the account token.
  unset ANTHROPIC_API_KEY ANTHROPIC_AUTH_TOKEN
  CLAUDE_CODE_OAUTH_TOKEN=$_la_token ROULETTE_ACCOUNT=$_la_name claude "$@"
}

cmd_use() {
  [ $# -ge 1 ] || die "usage: roulette use <name> [claude args...]"
  _name=$1
  shift
  require_account "$_name"
  _start=$(date +%s)
  launch_account "$_name" "$@"
```

```sh
record_usage() {
  has_account "$1" || return 0
  _ru_snap=$(printf '%s' "$2" | jq -c --argjson now "$(now)" '
    (.rate_limits // empty)
    | {five_hour: .five_hour.used_percentage,
       seven_day: .seven_day.used_percentage,
       resets_at: (.five_hour.resets_at // null),
       seen: $now}
    | select(.five_hour != null or .seven_day != null)' 2>/dev/null) || return 0

}

# statusline-hook [-- cmd...] — must never break the user's status line: always exit 0.
cmd_statusline_hook() {
  _payload=$(cat)
  _chained=0
  _out=
  if [ "${1:-}" = "--" ]; then
    shift
    _chained=1
    if [ $# -gt 0 ]; then
      _out=$(printf '%s' "$_payload" | "$@" 2>/dev/null)
    fi
  fi

  _acct=${ROULETTE_ACCOUNT:-}
  valid_name "$_acct" || _acct=
  _have_jq=0
  command -v jq >/dev/null 2>&1 && _have_jq=1

  if [ -n "$_acct" ] && [ "$_have_jq" -eq 1 ]; then
    (record_usage "$_acct" "$_payload") >/dev/null 2>&1
  fi

  if [ "$_chained" -eq 1 ]; then
    if [ -z "$_acct" ]; then
      printf '%s\n' "$_out"
    elif [ -n "$_out" ]; then
      printf '%s [%s]\n' "$_out" "$_acct"
    else
      printf '[%s]\n' "$_acct"
    fi
    return 0
  fi

  _bars=
  if [ "$_have_jq" -eq 1 ]; then
    _bars=$(printf '%s' "$_payload" | jq -r "$JQ_LIB"'
      (.rate_limits // {}) as $r
      | [ (if $r.five_hour.used_percentage != null
           then "5h \(bar($r.five_hour.used_percentage)) \($r.five_hour.used_percentage | round)%"
           else empty end),
          (if $r.seven_day.used_percentage != null
           then "7d \(bar($r.seven_day.used_percentage)) \($r.seven_day.used_percentage | round)%"
           else empty end) ]
      | join(" · ")' 2>/dev/null)
  fi
  _label=
  [ -n "$_acct" ] && _label="[$_acct]"
  if [ -n "$_label" ] && [ -n "$_bars" ]; then
    printf '%s %s\n' "$_label" "$_bars"
  else
    printf '%s%s\n' "$_label" "$_bars"
  fi
  return 0
}
```

- [ ] **Step 3: Write `install.sh`**

```sh
#!/bin/sh
# Install roulette into ~/.local/bin (or the directory given as $1).
set -e
dest=${1:-$HOME/.local/bin}
here=$(cd "$(dirname "$0")" && pwd)

command -v jq >/dev/null 2>&1 || echo "note: roulette needs jq — install it with: brew install jq" >&2

mkdir -p "$dest"
cp "$here/roulette" "$dest/roulette"
chmod +x "$dest/roulette"
ln -sf roulette "$dest/rt"

echo "installed $dest/roulette (shortcut: rt)"
case ":$PATH:" in
  *":$dest:"*) ;;
  *) echo "add $dest to your PATH to use it" ;;
esac
```

````markdown
# roulette

Switch Claude Code between **your own** subscription accounts in seconds —
no logging out and back in, and your conversation comes with you.

```
$ rt next
1) org2   you@client-b.com   5h ▱▱▱▱▱▱▱▱   3%   7d ▰▱▱▱▱▱▱▱  12%

Switch to [org2]:
```

## Install

Needs macOS, [jq](https://jqlang.github.io/jq/) and Claude Code.

```sh
git clone <this repo> && cd roulette && ./install.sh
```

This puts `roulette` and the shortcut `rt` in `~/.local/bin`.

## Add your accounts

For each account:

```sh
rt add work
```

roulette asks you to run `claude setup-token` in another terminal and sign in
as that account, then paste the token. It detects the account's login email
so you always see which account is which.

## Use

| Command | |
|---|---|
| `rt use work` | Start Claude Code on `work` |
| `rt next` | Pick another account and continue your last conversation there |
| `rt status` | Each account's login, 5-hour and 7-day usage, and how fresh that is |
| `rt list` | Accounts and logins |
| `rt refresh work` | Re-detect a login |
| `rt remove work` | Forget an account |

Everything after the account name is passed to `claude`, e.g. `rt use work --model sonnet`.

## Usage in your status line

roulette learns each account's usage from Claude Code's status line. In
`~/.claude/settings.json`, either use roulette's own status line:

```json
"statusLine": { "type": "command", "command": "roulette statusline-hook" }
```

or keep yours and let roulette tag along:

```json
"statusLine": { "type": "command", "command": "roulette statusline-hook -- node ~/.claude/hooks/statusline.js" }
```

Usage for an account is only as fresh as the last time you used it; `rt status`
shows how old each number is and marks estimated resets with `~`.

## Where your tokens go

- Each token is stored in the macOS Keychain as `roulette:<name>`.
- roulette hands it only to the `claude` process it starts, as
  `CLAUDE_CODE_OAUTH_TOKEN`. It never writes it to a file, prints it, or sends
  it anywhere.
- `~/.config/roulette/state.json` holds account names, login emails and usage
  percentages — nothing secret.

## What roulette does not do

roulette only switches accounts when **you** run a command. It does not rotate
accounts automatically, run unattended work across accounts, or help get
around usage limits. It is for people using their own subscriptions by hand.
For unattended, around-the-clock workloads, use the Claude API.

roulette is an independent project, not affiliated with Anthropic.
````
